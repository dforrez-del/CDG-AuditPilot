# État réel du développement
Un premier squelette WPF a été créé dans src/CDG.AuditPilot.Desktop.
Fonctions codées : clients/missions, import simple de questions JSON, notes d'entretien, constats avec score, actions, appel IA explicite, export HTML/CSV/SVG.
Limites : stockage JSON local non chiffré (pas SQLite), pas de véritables réponses par question, pas de bibliothèque versionnée, pas de preuves fichiers, pas de cartographie éditable, pas de DOCX/XLSX/PDF, pas de sauvegarde/restauration sécurisée, pas de rôles ni d'installateur signé.
La compilation Windows et la recette restent à vérifier via GitHub Actions. Usage avec données fictives uniquement.
